🐶 Pet Bath Machine (Java)

Projeto simples em Java que simula o funcionamento de uma máquina automática de banho para pets, desenvolvido com foco em Programação Orientada a Objetos (POO).

Este projeto foi criado para fins de estudo e portfólio, demonstrando conceitos básicos e importantes da linguagem Java.

📌 Funcionalidades

Colocar um pet na máquina

Dar banho no pet

Remover o pet da máquina

Abastecer água

Abastecer shampoo

Verificar nível de água

Verificar nível de shampoo

Verificar se há pet na máquina

Limpar a máquina

Menu interativo via terminal

🧠 Conceitos aplicados

Programação Orientada a Objetos (POO)

Encapsulamento

Separação de responsabilidades

Uso de classes e métodos

Controle de estado de objetos

Validação de regras de negócio

Entrada de dados com Scanner
